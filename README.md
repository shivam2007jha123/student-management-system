# Python Student Management System

A beginner-friendly **Student Management System** developed in Python as a Mini Project.

## 📌 Project Overview

This project allows users to manage student records through a simple menu-driven program. It demonstrates the Python concepts covered in Weeks 1–4.

## 🚀 Features

* Add student records
* View student records
* Search for a student
* Update student records
* Delete student records
* Store data using file handling
* Handle invalid user input and runtime errors
* Menu-driven interface

## 🛠️ Concepts Used

* Variables & Data Types
* Input & Output
* Conditional Statements
* Loops
* Functions
* Lists & Dictionaries
* File Handling
* Exception Handling
* Random Library
* Math Library
* Datetime Library

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code or any Python IDE.
3. Run:

```bash
python student_management.py
```

4. Follow the menu displayed on the screen.
